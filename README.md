# Para Bens — Gestão de Condomínios

Aplicação web para consulta de condomínios, cadastro de proprietários e inquilinos, importação Excel e acompanhamento de cobranças.

## Execução

Site estático: publique os arquivos da raiz na Vercel, sem framework ou comando de build.

## Dados

Não contém dados pessoais pré-carregados. Importações e cadastros são mantidos no navegador por IndexedDB. Esta versão ainda não implementa banco compartilhado nem autenticação de funcionários. Exporte backups antes de limpar dados do navegador. Dados do endereço antigo não são transferidos automaticamente para o novo endereço.
